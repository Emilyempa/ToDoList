# ToDo List 📝

Welcome to **ToDo List**, your simple yet powerful task management web application! This project is a combination of clean design and efficient functionality, built with the basics of **HTML**, **CSS**, and **JavaScript**. It's a great way to keep track of your tasks 🚀

---

## 🔧 Features
- **Add Tasks**: Quickly jot down all your to-dos.
- **Mark as Complete**: Keep track of your progress by marking tasks as done.
- **Delete Tasks**: Clean up your list when you're done with a task.
- **Local Storage Support**: Never lose your tasks! All your to-dos are saved, even if you close or refresh the page.
- **User-Friendly Design**: A minimal and intuitive interface for a seamless user experience.

---

## 🎨 Technologies Used
- **HTML**: For structuring the application.
- **CSS**: For styling, including hover effects and responsive design.
- **JavaScript**: For adding interactivity and local storage functionality.
